# 🛒 Melhor Preço - Comparador de Supermercados

O **Melhor Preço** é um buscador inteligente desenvolvido em Python com Flask que ajuda usuários a encontrarem as melhores ofertas em redes de supermercados e lojas de limpeza, filtrando resultados indesejados e facilitando a compra.

## 🚀 Funcionalidades
- **Busca Especializada:** Filtra resultados para focar em grandes redes (Carrefour, Pão de Açúcar, Extra, etc.).
- **Ordenação por Preço:** Exibe sempre as ofertas mais baratas primeiro.
- **Cópia Segura:** Botão de "Copiar Link" para evitar bloqueios de redirecionamento de navegadores.
- **Interface Responsiva:** Design limpo focado na experiência do usuário.

## 🛠️ Tecnologias
- [Python](https://www.python.org/)
- [Flask](https://flask.palletsprojects.com/)
- [SerpApi](https://serpapi.com/) (Google Shopping Engine)
- [Bootstrap 5](https://getbootstrap.com/)
